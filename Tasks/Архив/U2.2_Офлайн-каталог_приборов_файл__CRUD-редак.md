# КАРТОЧКА U2.2 — Офлайн-каталог приборов: файл + CRUD-редактор

## Цель
пользователь меняет характеристики приборов (расход, мощность, S обслуживания, габариты, типоразмеры) офлайн — без Revit и без пересборки.

## Описание (факт по коду)
каталог в JSON (`%AppData%\HVACLoadTerminals\catalog.json`, рядом с
  проектом — опция); загрузчик в Infrastructure (`JsonCatalogRepository` поверх существующего
  интерфейса `ITerminalCatalogRepository`); `SnapshotWorkspacePresenter.Calculate()`
  читает каталог извне (сейчас `CatalogFactory.CreateDemo()` захардкожен на месте —
  строка ~160); CreateDemo остаётся seed'ом при первом запуске; UI-редактор: модальное
  окно/вкладка с DataGrid CRUD по трём классам приборов + валидация (расход > 0 и т.п.);
  проект хранит путь/версию каталога.

## Входные данные
TerminalDevice-модель, CatalogFactory (14 типоразмеров) как образец.

## Задание
