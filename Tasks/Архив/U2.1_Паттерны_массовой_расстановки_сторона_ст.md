# КАРТОЧКА U2.1 — Паттерны массовой расстановки: сторона стены + правило одиночных

## Цель
правило владельца «приточные вдоль длинной границы, вытяжные вдоль короткой; отдельное правило для одиночных приборов» задаётся в UI и сохраняется в проекте.

## Описание (факт по коду)
- `CeilingPlacementOptions += WallPattern { CeilingGrid, LongSide, ShortSide, Explicit }`
    и правило одиночного прибора `SingleRule { Center, Corner }` (аналог
    `single_device_orientation` прототипа; сейчас захардкожен центр —
    `CeilingPlacementService.cs:125-127`);
  - настенные режимы переиспользуют готовое ядро `RoomGeometryAnalyzer` +
    `TerminalPlacementService` (SidePreference/CoordinateSystem/SpacingMm/StartOffsetMm/
    WallOffsetMm уже реализованы и покрыты тестами);
  - настройки в тулбаре ОБОИХ хостов раздельно для Притока и Вытяжки (дефолт владельца:
    Приток=LongSide, Вытяжка=ShortSide, одиночный=Center);
  - сериализация паттернов в `*.hvacproj.json` (round-trip);
  - на OxyPlot-плане показать выбранную сторону (подсветка ребра).
