- **Статус**: выполнено (код в репозитории), критерии приёмки проверены механически
- **Карточка**: `Tasks/Активные/U1.3_HTML-превью_WebView2_вместо_WebBrowser_б.md`
- **Исполнение**: перепроверка факта по коду + механическая верификация критериев.
  Реализация карточки зафиксирована коммитом `229143d` (plan/U1.3); текущая сессия
  проверила состояние на HEAD и подтвердила все критерии приёмки.

## Что было не так

`src/App/Views/HtmlPreviewWindow.xaml` держал легаси `WebBrowser` (IE-движок):
генератор `HtmlSceneExporter` не эмулировал IE11 → страница падала в IE7-mode,
`const`/Canvas не работали — «чёрный экран». Recompute в App был заглушкой
(`() => sceneJson`), ошибки `HtmlPreviewServer.Start()` не обрабатывались.
Общий WebView2-хост существовал только в ревит-стенде, App его не использовал.

## Что сделано

1. **Общий WebView2-хост в Infrastructure** (новый, обобщение ревит-хоста):
   - `src/Infrastructure/Visualization/WebView2PreviewWindow.xaml` и
     `src/Infrastructure/Visualization/WebView2PreviewWindow.xaml.cs` —
     загрузка сцены офлайн через `file://` (`HtmlSceneExporter.SaveToFile`),
     мост postMessage: host→page `{type:"scene"}`, page→host
     `{apply|cancel|recompute}`;
   - **Recompute — РЕАЛЬНЫЙ колбэк**: конструктор принимает
     `Func<string> recomputeSceneJson` — страница «Пересчитать» пересобирает
     сцену из актуального состояния (`WebView2PreviewWindow.xaml.cs:44`);
   - предзагрузка нативного `WebView2Loader.dll` нужной разрядности из
     `runtimes\` (лечит HRESULT 0x8007000B в win-x64 процессе,
     `WebView2PreviewWindow.xaml.cs:74`);
   - все ошибки — текстом в статусную строку окна, крах хоста исключён;
   - `LogSink` для подключения логгеров App/Revit.

2. **App**:
   - легаси `src/App/Views/HtmlPreviewWindow.xaml(.cs)` — удалены;
   - `src/App/Commands/OpenHtmlPreviewCommand.cs` — основной путь — общий
     `WebView2PreviewWindow` (modeless в App, чтобы менять параметры и жать
     «Пересчитать»); fallback при недоступности WebView2 — локальный
     `HtmlPreviewServer` + системный браузер; `HtmlPreviewServer.Start()`
     обёрнут try/catch → текст в статус, не краш (`OpenHtmlPreviewCommand.cs:85`);
   - `src/App/ViewModels/MainViewModel.cs` — сцена для превью строится из
     `Workspace.LastRawPlacements` (`BuildPlacementResults`); колбэк Recompute
     пересчитывает расстановку по текущим правилам количества вместо заглушки;
   - `src/App/HVACLoadTerminals.App.csproj` — NuGet `Microsoft.Web.WebView2`
     `1.0.4129.50`.

3. **Ревит-стенд**: `src/Revit/Visualization/WebView2PreviewWindow.xaml(.cs)`
   удалены, стенд переключён на общий хост из Infrastructure
   (`src/Revit/Commands/RevitHtmlPlacementCommand.cs`, `Revit.csproj`).

4. **Экспортёр**: `src/Infrastructure/Visualization/HtmlSceneExporter.cs` —
   кнопки страницы русифицированы: `Apply/Cancel/Recompute` →
   `Применить/Отмена/Пересчитать` (`HtmlSceneExporter.cs:166,173,178`).

  все пункты описаны фактом по коду, реализация уже присутствует в репозитории
  (коммит `229143d`, вердикт контролёра PASS), текущая сессия — механическая
  перепроверка критериев приёмки на HEAD.
- ASSUMPTION: не перезаписывал рабочее дерево и не правил реализацию — код на HEAD
  уже соответствует карточке и прошёл контроль; в этой сессии добавлен только
  отчёт по требуемому пути и сделан коммит артефакта отчёта.

## Открытые вопросы

- Локальный HTTP-сервер (`HtmlPreviewServer`) оставлен как fallback-путь
  (основной — офлайн `file://`); к удалению в U3.2, если не понадобится.
- Скриншот «после пересчёта» (`U1.3_webview2_after_recompute.png`) упоминался в
  прошлом отчёте, но в коммите `229143d` остался только `U1.3_webview2_preview.png`.
  Критерий приёмки требует один скриншот работающего превью — он на месте;
  повторный снимок после «Пересчитать» можно сделать при необходимости (U3.x).

## Как проверить

1. Открыть снимок → «▶ РАССЧИТАТЬ» → «🌐 HTML»: окно со схемой, пан/зум/тултипы.
2. Сменить правило количества притока → «Пересчитать» на странице: число точек
   меняется без закрытия окна.
3. Отключить сеть → превью продолжает работать (офлайн file://).
