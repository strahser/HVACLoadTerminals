## Что было не так

- Прошлые попытки завершались ошибкой: хвост сообщения в логе раннера пришёл
  мойбе-повреждённым (кодировка консоли), но при воспроизведении шага тестов
  выявлена фактическая причина — **файловая блокировка**:
  `dotnet test` падал с `MSB3021: Access to the path '...\xunit.abstractions.dll' is denied`,
  файл удерживал зависший процесс `testhost.net48`. После снятия блокировки
  (`Stop-Process testhost`) тесты проходят полностью.
- Отчёт прошлой попытки был записан как `Tasks/Отчёты/U1.2_Отчёт_2026-08-23.md`
  (без суффикса времени), тогда как раннер ожидает путь
  `Tasks/Отчёты/U1.2_Отчёт_2026-08-23_141419.md` — создан требуемый файл.
- Реализация карточки в коде присутствовала, но не была механически перепроверена
  на текущем состоянии ветки (после U2.1–U3.1) — выполнена проверка всех 4 критериев.

## Решения (grill)

- Блокирующих вопросов владельцу не возникло: реализация уже в ветке, критерии
  приёмки проверяемы механически по коду (см. ниже).
- ASSUMPTION: причина падения прошлых попыток — блокировка `testhost` файлов
  `bin\Debug\net48` (воспроизведена в этой сессии той же ошибкой MSB3021);
  мойбе-текст из лога раннера не поддаётся однозначной декодировке.

## Что сделано

### Модель строки — `src/Infrastructure/Presentation/Rows.cs`

`RoomRow.IsIncluded` — INPC-свойство, по умолчанию `true` (Rows.cs:16–22):

```csharp
private bool _isIncluded = true;
public bool IsIncluded
{
    get => _isIncluded;
    set { _isIncluded = value; OnPropertyChanged(nameof(IsIncluded)); }
}
```

### Presenter — `src/Infrastructure/Presentation/SnapshotWorkspacePresenter.cs`

- `Calculate()` обрабатывает только включённые комнаты: `includedRows = Rooms.Where(r => r.IsIncluded)`
  и ветка `if (!row.IsIncluded) continue;` в цикле (SnapshotWorkspacePresenter.cs:349, 368).
- Все комнаты выключены → статус **«Не выбрано ни одного помещения»**, расчёт не
  падает, возвращается пустое состояние с `IsCalculation = true` и очищенными
  размещениями (SnapshotWorkspacePresenter.cs:350–364).
- Счётчик выбранных в статусе расчёта: `Выбрано N из M · Размещение: …`
  (SnapshotWorkspacePresenter.cs:641).
- Групповые операции (SnapshotWorkspacePresenter.cs:296–317):
  `SetIncluded(filter, included)`, `IncludeLevel(levelName)` («включить уровень»),
  `IncludeOnlyVisible(visibleFilter)` («только видимые»), `CountIncluded()`.
- Round-trip проекта: `SaveProject`/`LoadProject` сериализуют `ProjectDto.Rooms`
  (список `RoomRow`) целиком через Newtonsoft → флаги `IsIncluded` сохраняются и
  восстанавливаются (SnapshotWorkspacePresenter.cs:508–596).
