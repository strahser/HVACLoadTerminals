## Что сделано (зафиксировано в истории git; код в репозитории)

### Общий хост (`src/Infrastructure/Visualization/WebView2PreviewWindow.xaml(.cs)`)

- загрузка сцены офлайн через `file://` (экспорт `HtmlSceneExporter.SaveToFile`),
  мост postMessage: host→page `{type:"scene"}`, page→host `{apply|cancel|recompute}`;
- **Recompute — РЕАЛЬНЫЙ колбэк**: конструктор принимает `Func<string> recomputeSceneJson`;
- предзагрузка нативного `WebView2Loader.dll` нужной разрядности из `runtimes\`;
- все ошибки — текстом в статусную строку окна, крах хоста исключён;
- `LogSink` для подключения логгеров App/Revit.

### App

- `src/App/Views/HtmlPreviewWindow.xaml(.cs)` (легаси WebBrowser) — **удалены**
  (в `src/App/Views` файлов Html/Preview нет);
- `src/App/Commands/OpenHtmlPreviewCommand.cs` — основной путь — общий
  `WebView2PreviewWindow` (modeless), fallback при недоступности WebView2 —
  локальный `HtmlPreviewServer` + системный браузер;
- `MainViewModel`: сцена для превью из `Workspace.LastRawPlacements`
  (`BuildPlacementResults`) — реальный колбэк Recompute вместо заглушки;
- `src/App/HVACLoadTerminals.App.csproj`: NuGet `Microsoft.Web.WebView2` 1.0.4129.50
  + post-build-копирование `WebView2Loader.dll` из `runtimes\win-x64\native\`.

### Ревит-стенд

- `src/Revit/Visualization/WebView2PreviewWindow.xaml(.cs)` — **удалены**
  (остался только `PlacementResultWindow`), стенд переключён на общий хост
  (`src/Revit/Commands/RevitHtmlPlacementCommand.cs`, csproj с копированием loader).

### Экспортёр

- `src/Infrastructure/Visualization/HtmlSceneExporter.cs`: кнопки страницы
  русифицированы — Apply/Cancel/Recompute → Применить/Отмена/Пересчитать.
