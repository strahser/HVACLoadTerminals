# S2.2 — Отчёт: расчётный расход на прибор CalculatedFlowM3h (2026-08-24 12:10)

**Карточка**: S2.2 плана `2026-08-24_named-systems-and-revit-conversion.md`
**Исполнитель**: интерактивная сессия агента.

## Что сделано

1. **`Core/Models/DevicePlacement.cs`**: `+= CalculatedFlowM3h : double` (settable,
   0 = не применим) — аналог `flow_to_device_calculated` прототипа.
2. **`Core/Services/CeilingPlacementService.cs`**: после размещения
   `CalculatedFlowM3h = requiredFlow / placements.Count` (фактически размещённое
   количество; при requiredFlow=0 поле остаётся 0).
3. **`Core/Services/TerminalPlacementService.cs`**: то же по
   `system.FlowRate / placements.Count` в `CalculateForSystem`.
4. **`Infrastructure/Presentation/Rows.cs`**: `PlacementRow += CalculatedFlow`;
   presenter `ToRows` переносит значение с округлением до 0,1.
5. **Колонка «Расход, м³/ч»** в таблицах размещений обоих хостов:
   `src/App/MainWindow.xaml`, `src/Revit/UI/SnapshotPlacementWindow.xaml`
   (рядом с «Система», формат F1).
6. **Сцена HTML**: `PlacementPointDto += CalculatedFlowM3h`;
   `PlacementSceneSerializer.BuildScene` заполняет из placement;
   JS-тултип `HtmlSceneExporter` показывает строку «Расход расч.: N м³/ч»
   (только когда >0); поле `Flow` (паспортный максимум типоразмера) сохранено.
7. **Тесты** `Core.Tests/CalculatedFlowTests.cs` (4 новых): потолочный сервис
   300/100 → 3 прибора по 100; нулевой расход → 0; настенный сервис сплитит
   FlowRate=300 системы «В1» на 3; сквозной presenter→rows→scene JSON содержит
   `CalculatedFlowM3h` и Σ по системе == расходу системы.
