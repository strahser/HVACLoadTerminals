Вывод сделан из кода, вопрос владельцу не требовался.
- ASSUMPTION: скриншоты «до/после» переиспользованы из попытки 1 (`Tasks/Отчёты/U1.1_артефакты/`), т.к. код фикса (`MainViewModel.cs:41`) и снимок данных не менялись между попытками; оба файла уже закоммичены и приняты контролёром (PASS). Повторная генерация требует поднятия реального окна App снимком `HvackFinal_v1.1.json` и не несёт новой информации.

## Что было не так

В `src/App/ViewModels/MainViewModel.cs` при смене уровня в ComboBox вызывался
`RoomsView.Refresh()`, но предикат `ICollectionView.Filter` нигде не назначался —
WPF показывал все комнаты всех уровней независимо от `SelectedLevel`.

## Что сделано

- `src/App/ViewModels/MainViewModel.cs:33-44` — при первом обращении к `RoomsView`
  (ленивая инициализация) теперь назначается предикат фильтрации:
  ```csharp
  public ICollectionView RoomsView
  {
      get
      {
          if (_roomsView != null)
              return _roomsView;
          _roomsView = CollectionViewSource.GetDefaultView(Workspace.Rooms);
          // U1.1: выбор уровня в ComboBox фильтрует таблицу помещений.
          _roomsView.Filter = o => o is RoomRow row && FilterVisible(row);
          return _roomsView;
      }
  }
  ```
- Предикат `FilterVisible` (`MainViewModel.cs:312-313`) уже существовал:
  `SelectedLevel == "Все уровни" || row.LevelName == SelectedLevel`. «Применить
  назначение» продолжает работать по видимым строкам (`ApplyPurpose(FilterVisible, …)`,
  `MainViewModel.cs:223`), план OxyPlot фильтровался самостоятельно — эти пути не менялись.
- `src/Revit/UI/SnapshotPlacementWindow.xaml.cs` — правок не требуется (см. grill Q1).
