## Что было не так (до U2.1)

`CeilingPlacementService` расставлял потолочные приборы только равномерной сеткой по
офсет-контуру; одиночный прибор всегда в центре (захардкожен). Правило владельца
«приточные вдоль длинной границы, вытяжные вдоль короткой; отдельное правило для
одиночных» в UI не задавалось, в `*.hvacproj.json` паттерны не сохранялись, на плане
выбранные стороны не подсвечивались.

## Что сделано (коммит `b71eabe`)

- **Core** (`src/Core/Services/CeilingPlacementService.cs`): `WallPattern
  { CeilingGrid, LongSide, ShortSide, Explicit }`, `SingleRule { Center, Corner }`;
  настенные режимы переиспользуют `RoomGeometryAnalyzer` + рёбра офсет-контура
  (`SelectPrimaryEdge`: LongSide/ShortSide → `SidePreference`, Explicit →
  `CoordinateSystem`); распределение по ребру с `StartOffsetMm`/`SpacingMm`;
  `SingleRule.Corner` — вершина офсет-контура у min-X/min-Y; узкая комната (офсет
  коллапсирует) → warning без падения; `CeilingPlacementResult.SelectedEdge` для
  подсветки.
- **Infrastructure/Presentation** (`SnapshotWorkspacePresenter.cs`, новый
  `PatternEdge.cs`): опции раздельно для Притока и Вытяжки, дефолты владельца
  (Приток=LongSide, Вытяжка=ShortSide, одиночный=Center), массивы для комбобоксов,
  проброс в `Calculate()`, round-trip паттернов в `ProjectDto` (StringEnumConverter,
  читаемые имена; старые файлы → дефолты владельца).
- **App** (`MainWindow.xaml`, `MainViewModel.cs`): комбобоксы паттернов Притока/Вытяжки
  и правила «1 прибор»; OxyPlot-план — подсветка выбранных рёбер толстой линией
  (приток красный, вытяжка зелёная).
- **Ревит-стенд** (`src/Revit/UI/SnapshotPlacementWindow.xaml`): те же контролы.
