## Что было не так (факт по коду, из карточки)

`src/App/Views/HtmlPreviewWindow.xaml` держал легаси `WebBrowser` (IE-движок): генератор
`HtmlSceneExporter` не эмулировал IE11 → страница падала в IE7-mode, `const`/Canvas не
работали — «чёрный экран». Recompute в App был заглушкой
(`() => sceneJson` в `OpenHtmlPreviewCommand.cs`), ошибки `HtmlPreviewServer` не
обрабатывались. Общий WebView2-хост существовал только в ревит-стенде.

## Что сделано (реализация из коммита 229143d, сверено с кодом на текущем HEAD)

### Общий хост (`src/Infrastructure/Visualization/WebView2PreviewWindow.xaml(.cs)`)

- Загрузка сцены офлайн через `file://` (`HtmlSceneExporter.SaveToFile`), мост postMessage:
  host→page `{type:"scene"}`, page→host `{apply|cancel|recompute}`;
- **Recompute — РЕАЛЬНЫЙ колбэк**: конструктор принимает `Func<string> recomputeSceneJson`
  (строка 44), страница «Пересчитать» пересобирает сцену из актуального состояния
  (`HandleRecompute`, строки 186–206);
- предзагрузка нативного `WebView2Loader.dll` нужной разрядности из `runtimes\`
  (`TryPreloadNativeLoader`, строки 74–90);
- все ошибки — текстом в статусную строку окна, крах хоста исключён (try/catch
  в `InitializeWebViewAsync`, `OnWebMessageReceived`, `HandleRecompute`);
- `LogSink` для подключения логгеров App/Revit.

### App

- Легаси `src/App/Views/HtmlPreviewWindow.xaml(.cs)` — удалены (в `src/App` нет ни одного
  файла с `WebBrowser`);
- `src/App/Commands/OpenHtmlPreviewCommand.cs` — основной путь: общий `WebView2PreviewWindow`
  (modeless в App — можно менять параметры и жать «Пересчитать»); fallback при недоступности
  WebView2 — `HtmlPreviewServer` + системный браузер; `HtmlPreviewServer.Start()` обёрнут
  try/catch → текст в статус (`StartServerAndOpenBrowser`, строки 77–108);
- `src/App/HVACLoadTerminals.App.csproj` — NuGet `Microsoft.Web.WebView2` 1.0.4129.50
  (строка 14) + `CopyWebView2Loader` (win-x64, строки 25–31).

### Экспортёр

- `src/Infrastructure/Visualization/HtmlSceneExporter.cs` — кнопки русифицированы:
  `Применить` (стр. 166), `Отмена` (стр. 173), `Пересчитать` (стр. 178).

### Ревит-стенд

- `src/Revit/Commands/RevitHtmlPlacementCommand.cs` — стенд переключён на общий хост
  из Infrastructure (собственный `WebView2PreviewWindow` в Revit удалён).

1. Открыть снимок → «▶ РАССЧИТАТЬ» → «🌐 HTML»: окно со схемой, пан/зум/тултипы работают.
2. Сменить правило количества притока → «Пересчитать» на странице: число точек меняется
   без закрытия окна.
3. Отключить сеть → превью продолжает работать (офлайн file://); 3D — внятное сообщение.
