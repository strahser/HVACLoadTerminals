## Что сделано

`src/App/ViewModels/MainViewModel.cs` — при первом обращении к `RoomsView`
теперь назначается предикат фильтрации (`MainViewModel.cs:33-46`):

```csharp
public ICollectionView RoomsView
{
    get
    {
        if (_roomsView != null)
            return _roomsView;
        _roomsView = CollectionViewSource.GetDefaultView(Workspace.Rooms);
        // U1.1: выбор уровня в ComboBox фильтрует таблицу помещений.
        _roomsView.Filter = o => o is RoomRow row && FilterVisible(row);
        return _roomsView;
    }
}
```

Раньше `RoomsView.Refresh()` в сеттере `SelectedLevel` вызывался, но предикат
`.Filter` не был назначен — таблица не реагировала на выбор уровня.
Больше ничего не менялось: `FilterVisible` уже использовался «Применить
назначение» (`ApplyPurpose` работает по видимым), план OxyPlot фильтровался
самостоятельно.

### Ревит-хост

`src/Revit/UI/SnapshotPlacementWindow.xaml.cs` проверен по условию карточки:
своего `ICollectionview` он не держит (`RoomsGrid.ItemsSource = state.Rooms`,
сырой ребиндинг) и ComboBox уровней не имеет — фикс к нему неприменим,
изменения не требуются.

Инструментальная проверка (харнесс поднимает реальное окно App c тем же
MainViewModel из AppHost DI):

```
levels=Все уровни | Уровень 2 | Уровень 1 | Уровень 3
BEFORE level='Все уровни' visibleRows=40
SELECT level='Уровень 2'
AFTER  level='Уровень 2' visibleRows=13
BACK   visibleRows=40          ← возврат «Все уровни» показывает все 40
```

«Применить назначение» продолжает работать по видимым строкам — код
`Workspace.ApplyPurpose(FilterVisible, …)` не менялся.

## Наблюдение вне скоупа карточки

Сразу после «Открыть снимок…» (до нажатия «РАССЧИТАТЬ») ComboBox содержит
только «Все уровни»: presenter (`SnapshotWorkspacePresenter.RaiseState`) шлёт
состояние без `Levels`; список уровней заполняется только в `BuildState`
после расчёта. Существующее поведение не тронуто — предложено план-раннеру
как отдельная карточка при необходимости.
