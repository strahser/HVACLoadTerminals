## ИНСТРУКЦИЯ ПРОГОНА ДЛЯ ВЛАДЕЛЬЦА (S4.1 → S4.2)

1. Открыть Revit 2024 → рабочую КОПИЮ `ТестыОВ\newBuilding\HvackFinal.rvt`.
2. Вкладка **HVAC Terminals** → «По снимку помещений» → выбрать снимок уровня из
   `%AppData%\HeatLossRevit2\data\snapshots_raw\...` (например HvackFinal_v1.1.json).
   В сводке: помещения/приборы/предупреждения → режим «Разместить всё» (первый прогон).
3. Проверить:
   - Диспетчер механических систем: существуют системы с именами П1/В1 (или П1+П2,
     если задать комнате две приточные через стенд/App);
   - приборы внутри систем (Select All Instances → выделение по системам);
   - расход на приборе = расчётный (Σ расходов системы / N), НЕ паспортный максимум;
   - параметр «ИмяСистемы» заполнен (если есть в семействе);
   - радиаторы без коннекторов дали warning «записаны только параметры», не падение.
4. Повторный прогон той же кнопкой: «Пропустить» → 0 новых элементов;
   «Заменить» → элементы пересозданы, системы НЕ задублировались (S4.1-ассерты b/d).
5. Стенд расстановки: править комнаты (кнопка «Системы…»: П1=120/П2=80/В1=200),
   «Записать» → статус-строка покажет «системы: П1×a, П2×b, В1×c»; скриншот сводки —
   артефакт для закрытия S3.2/S1.2.
6. App: открыть тот же снимок → РАССЧИТАТЬ → «⬇ Задание JSON» → проверить две
   группы точек с разными system_name для комнаты с двумя системами.
7. Полученный вердикт записать в ревью-блок плана (закрывает S4.2 и C4.1
   родительского плана); замечания — новыми карточками.
